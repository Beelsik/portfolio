# Шпаргалка по портфолио и откликам

## Главное: куда выложить страницу вместо `claude.ai/artifact`

Не отправляйте заказчикам ссылку вида `https://claude.ai/artifact/...` — вокруг неё висит шапка Claude, и любой технический заказчик с первой секунды понимает, что страницу сгенерировали одним промптом.

Сейчас в папке лежат полностью автономные `index.html` и `portfolio.html` (одинаковые файлы, без привязки к `window.claude` и без внешних библиотек — даже генерация `.docx` и `.csv` работает прямо в браузере).

### Вариант А — GitHub Pages (лучший вариант для разработчика, 2 минуты)
Ссылка будет выглядеть как ваш личный стенд: `https://beelsik.github.io/portfolio/`

```powershell
cd "C:\Users\mogil\Desktop\проект\portfolio"
git init
git add index.html claude-code-kit
git commit -m "Initial portfolio sandboxes"
# Создайте пустой публичный репозиторий portfolio на github.com/new, затем:
git branch -M main
git remote add origin https://github.com/Beelsik/portfolio.git
git push -u origin main
```
После пуша на GitHub зайдите в **Settings → Pages → Build and deployment → Source: Deploy from a branch (`main` / `/root`) → Save**. Через минуту страница откроется по чистому адресу `https://beelsik.github.io/portfolio/`.

*(Отдельно папку `claude-code-kit/` стоит залить в самостоятельный репозиторий `https://github.com/Beelsik/claude-code-guardrails` — прямая ссылка на GitHub-репозиторий с проходящими тестами `node --test` даёт огромный плюс на Codeur, Freelancehunt и Useme).*

### Вариант Б — Cloudflare Pages или Netlify Drop (за 30 секунд без консоли)
Откройте `https://pages.cloudflare.com` (Create application → Upload assets) или `https://app.netlify.com/drop` и перетащите туда файл `index.html`. Получите чистый домен вида `https://beelsik-dev.pages.dev`.

### Вариант В — Облако 24/7 с живым ИИ (работает даже при выключенном ПК)
Чтобы работал **живой ИИ-бот по API** и ваш ПК можно было выключать, ключ API нельзя зашивать в `index.html` на GitHub Pages (его увидят в коде браузера). Нужен сервер, который держит ключ в секрете — например, бесплатный **Render.com** (конфиг [render.yaml](render.yaml) уже готов) или **Koyeb**:

1. Залейте папку `portfolio` на GitHub в публичный или приватный репозиторий `portfolio`.
2. Получите бесплатный API-ключ на `https://build.nvidia.com` (кнопка **Get API Key** у любой модели, например `meta/llama-3.3-70b-instruct` — формат ключа `nvapi-...`, базовый URL `https://integrate.api.nvidia.com/v1`).
3. Зайдите на `https://render.com` → **New + → Blueprint** (или **Web Service**) → выберите репозиторий `portfolio`.
4. В переменных окружения (`Environment`) вставьте `LLM_API_KEY = nvapi-...` (остальное уже прописано в `render.yaml`).
5. Получите постоянный URL вида `https://beelsik-portfolio.onrender.com` — он работает 24/7 при выключенном ПК *(на бесплатном тарифе Render сервер «засыпает» после 15 минут простоя и просыпается за ~20–30 секунд при первом открытии)*.

### Вариант Г — Хостинг у себя на ПК в Docker + живой ИИ-бот через API
В папке уже лежат [Dockerfile](Dockerfile), [docker-compose.yml](docker-compose.yml), [server.mjs](server.mjs) и [.env.example](.env.example).

1. Скопируйте `.env.example` в `.env` и впишите ключ от любого провайдера (`OpenAI`, `OpenRouter`, `DeepSeek`, `Anthropic Claude`, `Google Gemini`) или выберите локальную `Ollama`:
   ```powershell
   cd "C:\Users\mogil\Desktop\проект\portfolio"
   Copy-Item .env.example .env
   notepad .env
   ```
2. Запустите контейнер (Docker у вас уже установлен):
   ```powershell
   docker compose up -d --build
   ```
3. Откройте `http://localhost:3000`.
   - В стенде **01 (Чат клиники)** появится бейдж `LLM: <ваша модель>` и переключатель **«Операторы заняты → ИИ» / «Оператор свободен»**: когда операторы заняты, отвечает настоящий ИИ по API, записывает в слоты и отправляет лид/handoff в CRM; когда оператор свободен — бот уходит в ожидание.
   - Стенды **02 (RAG)** и **05 (Карточки eBay)** также автоматически переключаются на живой API, а если ключ не задан — всё продолжает работать на локальном движке.
4. **Как показать живого бота заказчику с вашего ПК:**
   - На созвоне — просто покажите экран на `http://localhost:3000`.
   - По временной публичной ссылке — поднимите бесплатный Cloudflare Quick Tunnel одной командой (если установлен `cloudflared`):
     ```powershell
     cloudflared tunnel --url http://localhost:3000
     ```
     Он выдаст временный HTTPS-адрес вида `https://xxxx.trycloudflare.com` (в `server.mjs` уже встроен лимит `RATE_LIMIT_MAX=40` запросов с одного IP за 10 минут, чтобы никто не сжёг ваш баланс API).

## Где поменять имя и контакты на странице

Откройте `portfolio.html` (и скопируйте изменения в `index.html`) — в начале блока `<script>` (около строки 665) находится объект `PROFILE`:

```js
const PROFILE = {
  brand: 'beelsik',
  githubUrl: 'https://github.com/Beelsik',
  githubLabel: 'github.com/Beelsik',
  extraLinkUrl: '',   // например: 'https://t.me/ваш_ник' (не вставляйте для Kwork, где запрещены контакты!)
  extraLinkLabel: '', // например: 't.me/ваш_ник'
};
```

> **Важно про Kwork и Freelancehunt:** модерация Kwork режет внешние ссылки с прямыми контактами (Telegram/почта/телефон). Пока поле `extraLinkUrl` пустое, на странице нет прямых мессенджеров, а в подвале написано «ответьте в переписке на площадке» — такую ссылку безопасно прикладывать как демонстрацию работ (а для Kwork дополнительно сделайте 4–5 скриншотов стендов в светлой/тёмной теме и загрузите их прямо в альбом портфолио профиля).
